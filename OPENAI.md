 # OpenAI Codex CLI Codebase Overview

 ## Introduction

 The OpenAI Codex CLI is a terminal-based coding assistant that allows you to interact with and modify your codebase using natural language. It leverages OpenAI models to:
 - Read and understand your project files.
 - Generate, modify, and apply code changes.
 - Execute commands in a sandboxed environment.
 - Integrate with Git for version control.

 ## Core Components

 - **CLI (`cli.tsx`, `cli_singlepass.tsx`):** Entry points for interactive and non-interactive modes.
 - **Agent Loop (`agent-loop.ts`):** Coordinates between the model, file changes, and shell execution.
 - **Apply-Patch (`apply-patch.ts`):** Parses and applies code modifications as Git-friendly diffs.
 - **Sandboxing:** Isolates executed commands via macOS Seatbelt or Docker on Linux, blocking unwanted network access.
 - **UI Components:** Built with React (Ink) to render terminal overlays, chat history, typeahead suggestions, and more.
 - **Parsers & Utilities:** Handle token counting, project documentation memory, command formatting, and Git integration.

 ## Usage

 1. **Install:** `npm install -g @openai/codex`
 2. **Configure:** Set `OPENAI_API_KEY` in your environment.
 3. **Run:**
    - Interactive: `codex`
    - Single-pass: `codex "explain this codebase to me"`
 4. **Approval Modes:**
    - Suggest (default): prompts before file writes and commands.
    - Auto Edit: applies file writes automatically.
    - Full Auto: applies writes and executes commands without prompting.
